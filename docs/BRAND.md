# Brand

## Logo

![SmartQueue logo](logo.svg)

The icon-only mark (for favicons, app icons, avatars):

<img src="logo-mark.svg" width="64" height="64" alt="SmartQueue mark" />

The mark reads as three people approaching the front of a line — two outlined circles waiting, and a filled circle with a checkmark for the one currently being served. It mirrors the queue concept directly: wait, get closer, get served.

## Slogan

**Queues, made invisible.**

The product removes the physical line — people check a position and an estimate instead of standing in one.

## Colors

Pulled directly from the live app theme (`frontend/src/styles.css`):

| Token | Hex | Use |
|---|---|---|
| Background | `#09090b` | App background, logo tile |
| Primary (brand) | `#10b981` | Accent, "served" state, primary actions |
| Text | `#fafafa` | Primary text on dark background |
| Text muted | `#a1a1aa` | Secondary text, waiting states |

## Typography

- **Sans:** Inter — UI text, wordmark
- **Mono:** JetBrains Mono — tagline, token numbers, code
