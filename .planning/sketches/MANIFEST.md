# Sketch Manifest — SmartQueue Enterprise Redesign

## Design Direction
Enterprise-grade SaaS product targeting hospitals, clinics, government offices, and banks.
Inspired by Linear, Stripe, and Vercel — precise, trustworthy, and efficient.
The UI should feel like a tool professionals rely on daily, not a consumer app.

## Reference Points
- **Linear** — dark sidebar, high information density, keyboard-first
- **Stripe** — clean light surfaces, meticulous typography, data clarity
- **Vercel** — near-black backgrounds, minimal chrome, monospace accents
- **Notion** — calm neutrals, no harsh contrasts, legible hierarchy
- **Clerk** — enterprise auth, professional yet approachable
